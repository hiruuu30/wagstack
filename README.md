# WagStack — Brick & Bond pet-care workspace v23

This build starts from v20 and applies the full queued markup/instruction set approved before the user said “Do the build now.”

## Pawfile dashboard
- Grooming uses a pet grooming comb/brush icon, not a paint brush.
- Pawfile Summary / Everything in one place strip is removed.
- Top area is now a two-part composition: TFA brand mark/wordmark area on the left and one large swipeable Updates bento carousel on the right.
- Updates carousel supports swipe/drag, arrows and dots.
- Fur Parent rail action #1 is a chat bubble that opens the actual Fur Parent ↔ WagStack local chat box.
- Notifications and cart keep numeric badges.
- Floating dog chat launcher is removed.
- About is added to the left rail and has a dedicated brand page.
- Edit Profile is added beneath Fur Parent identity and has a dedicated editable profile page with local photo upload.
- Rail icons now use a uniform duotone/orange treatment matching Pawfile.

## My Pets → Health
- Vaccinations, Deworming and Flea & Tick keep their specific icons.
- Every health card has an Edit button.
- A fourth Add Health Detail card provides a dropdown for Allergy, Medication, Surgery, Condition, Vet Visit, Weight Record, Dental Care, Lab/Test Result and Other.
- Adding a detail opens an editor; edits persist to localStorage.

## My Pets → Appointments
- Default demo data contains Full Grooming, Nail Trim + Ear Care, and a Hotel Stay so the booking CTA is the fourth card in a fresh workspace.
- Fourth card offers separate Book Grooming and Book Hotel Stay actions.
- Nail Trim + Ear Care retains scissors.
- Full Grooming uses the grooming comb/brush icon.
- Hotel stays use a dog-house icon.

All data remains local demo data stored in the browser. No external icon CDN is required.


## v22 — Per-pet health + stronger appointment controls
- Health records are now stored independently for each pet.
- Health add menu is a custom dropdown with fixed categories and category-specific duotone icons.
- Only the Other category permits a custom title.
- Health cards have larger Edit and Delete actions.
- My Pets > Appointments booking cards have larger Edit and Delete actions.
- Booking CTA buttons are enlarged and right-weighted on desktop.
- Booking records can be edited or deleted locally.

## v23 branding
- Rebranded the product from The Furr Avenue to WagStack.
- Added the approved W-as-wagging-tail brandmark with orange motion echoes.
- Added the lowercase `wagstack.` wordmark treatment and `by Brick & Bond` lockup.
- Applied WagStack to the dashboard brand slot, chat, About page, document metadata and favicon.
